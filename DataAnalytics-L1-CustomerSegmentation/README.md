# Customer Segmentation using K-Means Clustering

## Project Overview
This project performs customer segmentation using the K-Means Clustering algorithm in Python. The aim is to group customers based on their annual income and spending score.

## Dataset
The dataset used is Mall Customers Dataset (`Mall_Customers.csv`).

It contains 200 customer records with the following features:
- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Steps
1. Loaded the dataset using Pandas.
2. Checked the dataset shape, data types, missing values, and duplicates.
3. Selected Annual Income and Spending Score as clustering features.
4. Applied the K-Means Clustering algorithm with 5 clusters.
5. Visualized the customer segments using a scatter plot.
6. Analyzed the average income and spending score of each cluster.

## Key Findings
- The dataset contains 200 customers.
- No missing values or duplicate records were found.
- Customers were divided into 5 clusters.
- The clusters represent different income and spending patterns.

## Marketing Recommendations
- Target high-income, high-spending customers with premium offers.
- Provide personalized offers to low-income, high-spending customers.
- Use loyalty programs to retain regular customers.
- Encourage low-spending customers with suitable promotions.

## Limitation
The clustering is based on annual income and spending score only. Other customer characteristics may also influence purchasing behavior.

## Conclusion
K-Means Clustering helps identify different customer groups and supports businesses in planning targeted marketing strategies.
