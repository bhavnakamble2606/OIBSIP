# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand sales trends, customer purchasing patterns, and product category performance.

## Dataset
The project uses a retail sales dataset containing transaction details, customer information, product categories, quantities, and sales amounts.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Checked dataset shape, data types, missing values, and duplicate records.
- Calculated descriptive statistics.
- Analyzed monthly and quarterly sales trends.
- Explored customer age and gender patterns.
- Identified the top 10 transactions by total amount.
- Visualized revenue by product category.
- Created a correlation heatmap.

## Key Findings
The analysis helps identify sales trends, customer purchasing patterns, and category-wise revenue performance.

## Conclusion
EDA provides useful insights into retail sales data and can help businesses make better decisions.
