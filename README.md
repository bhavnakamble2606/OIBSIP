# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The objective is to understand sales trends, customer purchasing patterns, and product category performance through statistical analysis and visualizations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
- Total transactions: 1,000
- Number of columns: 9
- Total revenue: 456,000
- Average transaction amount: 456
- Average customer age: 41.39 years

## Analysis Performed
- Dataset structure and data type inspection
- Missing values and duplicate record checks
- Mean, median, mode, and standard deviation
- Monthly and quarterly sales trends
- Gender-wise sales analysis
- Age-group sales analysis
- Revenue by product category
- Top 10 transactions by sales
- Correlation heatmap
- Product category-wise transaction counts

## Key Findings
- **Highest-revenue category:** Electronics (156,905)
- **Second-highest-revenue category:** Clothing (155,580)
- **Third-highest-revenue category:** Beauty (143,515)
- **Female customer revenue:** 232,840
- **Male customer revenue:** 223,160
- **Highest-revenue age group:** 46–55 (100,690)

## Recommendations
1. Monitor demand and maintain appropriate inventory for Electronics.
2. Consider targeted promotions to improve Clothing sales.
3. Study the purchasing patterns of customers aged 46–55.
4. Analyze customer preferences to plan relevant marketing campaigns.
5. Use monthly and quarterly sales trends to plan promotional activities.

## Dataset Limitation
The dataset contains product categories but does not include individual product names. Therefore, the analysis identifies the top 10 transactions instead of the top 10 individual products.

## Project Files
- `retail_sales_eda.ipynb` — Jupyter Notebook containing Python code, analysis, and visualizations.
- `retail_sales_dataset.csv` — Dataset used for the analysis.

## Conclusion
This project demonstrates how Python-based exploratory data analysis can help identify retail sales patterns and support data-driven business decisions.
